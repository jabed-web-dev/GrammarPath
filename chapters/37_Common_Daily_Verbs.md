# Common Daily Verbs
**বাংলা:** প্রতিদিনের কাজে ব্যবহৃত গুরুত্বপূর্ণ Verb

> কথা বলা, চলাফেরা, কাজ ও দৈনন্দিন কাজের ক্রিয়া। প্রতিটি শব্দের অর্থের সঙ্গে উদাহরণ বাক্য পড়ো এবং নিজের জীবনের বাক্য তৈরি করো।

## শেখার লক্ষ্য
- শব্দের বাংলা অর্থ বুঝতে পারা।
- বাস্তব কথোপকথনে শব্দগুলো ব্যবহার করতে পারা।
- উদাহরণ দেখে নিজে বাক্য তৈরি করা।

## Vocabulary List
| English | বাংলা অর্থ | Example Sentence |
|---|---|---|
| **ask** | জিজ্ঞাসা করা | Can I ask you a question? |
| **answer** | উত্তর দেওয়া | Please answer me. |
| **bring** | নিয়ে আসা | Please bring some water. |
| **carry** | বহন করা | I can carry this bag. |
| **choose** | বেছে নেওয়া | Choose the one you like. |
| **decide** | সিদ্ধান্ত নেওয়া | I need time to decide. |
| **explain** | ব্যাখ্যা করা | Can you explain this? |
| **forget** | ভুলে যাওয়া | Do not forget your keys. |
| **remember** | মনে রাখা | Remember my number. |
| **happen** | ঘটা | What happened yesterday? |
| **hurry** | তাড়াহুড়া করা | Please hurry up. |
| **invite** | আমন্ত্রণ জানানো | They invited me to dinner. |
| **join** | যোগ দেওয়া | Can I join you? |
| **leave** | চলে যাওয়া / ছেড়ে যাওয়া | I leave home at eight. |
| **lend** | ধার দেওয়া | Can you lend me a pen? |
| **borrow** | ধার নেওয়া | May I borrow your phone? |
| **miss** | মিস করা / না পাওয়া | I missed the bus. |
| **offer** | প্রস্তাব দেওয়া | They offered me a job. |
| **order** | অর্ডার করা | I want to order food. |
| **pay** | টাকা পরিশোধ করা | Can I pay by card? |
| **pick** | তুলে নেওয়া / বেছে নেওয়া | Please pick up the package. |
| **receive** | গ্রহণ করা / পাওয়া | I received your email. |
| **return** | ফিরে আসা / ফেরত দেওয়া | I will return tomorrow. |
| **share** | ভাগ করে নেওয়া | Let us share the food. |
| **wait** | অপেক্ষা করা | Please wait here. |
| **check** | পরীক্ষা করা | Please check the address. |
| **fix** | মেরামত করা / ঠিক করা | Can you fix this problem? |
| **improve** | উন্নতি করা | I want to improve my English. |

## অনুশীলন
1. তালিকা থেকে ১০টি শব্দ বেছে নিয়ে বাংলা অর্থ না দেখে মনে করার চেষ্টা করো।
2. ৫টি শব্দ দিয়ে নিজের সম্পর্কে ইংরেজি বাক্য লেখো।
3. উদাহরণ বাক্যগুলো জোরে জোরে পড়ো।
